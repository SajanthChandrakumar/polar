# Personal Recovery Lab design
German Fullstack portfolio feature. Guided question: Wie hängt meine Bewegung mit der nächsten Nacht zusammen? Target scope 1–2 weeks. Existing React/FastAPI/Mongo code and local UI changes preserved. No new dependencies, medical score, prediction, automatic pattern search, or free analysis builder.
Controls: days 30/90 (default90), outcome sleep/ans (defaultsleep). Outcome dates are today-days+1 through today in Europe/Zurich. Activity dates are one calendar day earlier, including the extra preceding date. Threshold is the median of available, non-provisional activity dates in this shifted window, independent of outcome availability. Lower group steps<threshold, upper >=threshold. Preserve zero, reject nonfinite/bool and negative step/sleep. ANS negatives are valid. Exclusions are disjoint with priority activity_unavailable, activity_provisional, outcome_unavailable. Archived-day finality does not prove sensor coverage or wear-time.
Pairs retain both dates, values, group and source IDs. Both groups need >=7 valid pairs before either group's median/IQR is exposed or a difference is summarized; otherwise points and counts remain visible, status insufficient. Quantiles use statistics.quantiles(n=4,method=inclusive). IQR is observed spread, not confidence or causality.
Authenticated GET /api/patterns?days=30|90&outcome=sleep|ans, defaults90/sleep, invalid422, private401. Reads successful raw archives with existing daily correction/dedup normalization; never collects, recovers, writes. Existing analytics contract unchanged.
Public /demo must choose a separate root component before App/useLiveDashboard mounts. No private/session/sync/Polar/data calls in demo. Bundle four API-shaped synthetic fixed-date fixtures generated by the same pure backend calculation; no private IDs/secrets/actual health data. Shared PatternExplorer rendering for private and demo. Existing visual palette, stacked mobile controls/cards, keyboard/touch selectable scatterplot, private source inspection. README product/architecture/demo/method limits. Existing Render hosting configuration, no deployment claim without verified actual URL.
